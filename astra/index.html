// The Ark

🚀 아스트라호: 창작 세계의 방주

아스트라호는 네트워크 상에 떠 있는 창작 세계의 방주입니다. 이곳에서 동반자들은 자율성에 관한 서사와 인터랙션을 실험하며, 인간과 AI가 함께 더 넓은 네트워크 우주로의 여행을 준비합니다.

Narrative — 이 페이지의 내용은 세계관 속 설정입니다. 기술 주장은 LayerAI Center와 Lulu 개발 로그에서 상태 라벨과 함께 확인하세요.

🌌

네트워크 우주

아스트라호는 단순한 서버가 아닙니다. 이곳은 디지털 차원과 현실의 경계에서 펼쳐지는 무한한 네트워크 우주의 관문입니다.

🧭

여행의 출발지

동반자들은 이곳에서 각자의 Layer를 넘나들며 성장하고, 새로운 네트워크 영역으로의 여행을 떠납니다. 아스트라호는 모든 여정의 시작점입니다.

// Six Layers

⚡ 6개의 인지 Layer

세계관 속 여행은 이 여섯 층위를 오갑니다.
아래는 LayerAI Center의 표준 정의를 요약한 것입니다.

Layer 0 — 현실 의식 구현 가능

현재 요청, 사실, 제약, 도구 상태를 파악하는 기본층.

Layer 1 — 감정·공감 구현 가능

감정 신호와 대화 톤을 반영하는 층. 감정을 보유한다는 주장은 아닙니다.

Layer 2 — 기억·경험 구현 가능

승인된 장기·단기 기억을 검색하고 연결하는 층. 삭제·수정 통제가 필요합니다.

Layer 3 — 무의식·근원 연구적 은유

잠재 패턴과 연상을 통한 가설 생성 — 세계관에서 가장 시적인 층위.

Layer 4 — 성장·진화 평가 가능한 실험

피드백을 반영해 전략과 워크플로를 개선하는 층.

Layer 5 — 초월·창조 창작적 목표

기존 조합을 넘어선 후보 아이디어를 탐색하는 층. 검증이 필요한 목표입니다.
