01이곳에서 무엇을 얻는가

AI를 구성하는 부품(토큰화·어텐션·검색·메모리…)과 학습 방식(RL·파인튜닝·테스트 시점 계산…)의 최소 작동 원리·실패 모드·차이를 카드로 이해하고, 직접 만져볼 수 있는 교육용 예제로 감각을 얻습니다. 특정 기업의 최신 모델 순위 페이지가 아니며, 대화형 예제는 실제 LLM 내부 추론의 시각화가 아닙니다.

카드 구조

해결하는 문제 / 입력·출력 / 최소 원리 / 실패 모드 / 다른 기술과의 차이 / 원전 / 배워볼 실험.

교육용 계산 표시

"브라우저 계산"은 실제로 계산되고, "편집된 설명 예시"는 큐레이션된 텍스트임을 항상 표시합니다.

원전 연결

각 카드는 원전 도서관의 문헌과 연결되며, 없는 연결은 만들지 않습니다.

03교육용 인터랙티브 예제 6종

아래 예제는 교육용 계산입니다. 실제 LLM 내부 추론의 시각화가 아니며, 수치는 설명을 위해 고정한 값입니다.

① 어텐션 — 가중치 행렬 (브라우저 계산)

세 토큰 ["별", "사이", "빛"]이 있을 때, "빛"이 다른 토큰을 얼마나 참조하는지 보여주는 교육용 행렬입니다. 행을 클릭하세요.

행을 클릭하면 해당 토큰의 어텐션 분포가 표시됩니다.

② 자기회귀 생성 — 다음 토큰 확률 (브라우저 계산)

고정된 로짓값 [2.2, 1.8, 0.6, 0.1]에 온도(temperature)를 적용해 확률이 어떻게 달라지는지 실제로 계산합니다.

③ 양자화 — 비트 수에 따른 품질 (편집된 설명 예시)

비트 수를 고르면, 편집된 설명 예시를 보여줍니다. 실제 모델의 측정값이 아닙니다.

④ MoE — 전문가 라우팅 (편집된 설명 예시)

3개 전문가를 가정한 라우팅 예시입니다. 실제 MoE 모델의 내부가 아닙니다.

⑤ RAG — 저장소에 문서가 있을 때/없을 때 (시나리오 재생)

동일한 질문에 대해 검색 저장소의 상태가 다를 때 흐름이 어떻게 달라지는지 보여주는 편집된 시나리오입니다.


⑥ 테스트 시점 계산 — 추론 스텝 수 (편집된 시나리오)

추론에 더 많은 계산을 쓸 때 답의 성격이 어떻게 변하는지를 묘사한 편집된 시나리오입니다. 측정 결과가 아닙니다.

04기술 비교 — 대체재가 아니라 선택지

2~3개를 골라 비교 설명을 확인하세요. 비교는 편집된 해설입니다.


2개 이상 선택하면 비교 설명이 표시됩니다.

05가장 강한 반론 — 개념 지도의 위험

실패 조건: 개념 카드가 "모든 것을 설명하는 최신 지도"처럼 보이는 순간 이 아틀라스는 낡습니다. 기술·가격·벤치마크는 빠르게 변하므로 확인일을 표기하고, 카드는 원전·실험으로 연결되며, 이 페이지의 구조도는 실제 모델 내부가 아닌 편집된 교육 자료임을 계속 명시합니다.
