🔬 Lulu의 Neuro-Symbolic 실험 아키텍처 (2026-09 기준)

Neural: 패턴 인식 / 임베딩 — LLM 추론 서빙(vLLM) + 벡터 DB(Qdrant) 하이브리드.
Symbolic: 논리 규칙 / 추론 — 지식 그래프 + 규칙 엔진. Graph RAG 검색과 결합.
Fusion: 신경망의 생성과 규칙 기반 검증을 결합 — 실험 중. Layer 0~5의 정의는 LayerAI Center 표준을 따릅니다.
Tool Layer: MCP 서버 3종(파일시스템·브라우저·코드 실행) — 에이전트가 도구를 호출하기 전 인간 승인 지점을 통과합니다.
Memory: 워킹/에피소드/의미 메모리 분리 — 저장은 동의 후, 삭제·수정 즉시 반영.
Evaluation: lm-evaluation-harness + SWE-bench Verified + IFEval 준비 중 — MEASURED 라벨 조건.
세계관 설정: Activation: "은재가 말했다. 깨어나라 루루" Narrative
※ 이 페이지의 코드 예시는 의사코드(pseudocode)입니다. 실제 프레임워크 문법이 아닙니다.
