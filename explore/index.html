01이곳에서 무엇을 얻는가

확장 페이지 전체에서 내 관심과 시간에 맞는 항로를 찾습니다. 필터는 태그·시간·난이도 기반 규칙이고, 주제 2개를 고르면 추천 근거(공통 태그)를 보여주며 3~5개 항로를 제안합니다. 지도 개요는 HTML로 만든 안내 시각화이며, 좌표·거리는 의미 거리가 아닙니다.

필터 초기화·상태 복원

필터는 언제든 초기화할 수 있고, 선택한 항로는 노트북에 저장됩니다. URL에는 개인 내용을 넣지 않습니다.

추천 규칙 보기

항로마다 "어떤 태그가 매칭됐는지"를 표시합니다. 나중에 추천 API로 교체해도 같은 자리에 표시됩니다.

30개 페이지 전부 공개

R1~R3 전 단계가 공개되었습니다. 아래 상태표가 전체 구현 현황입니다 — 빈 페이지는 없습니다.

04지도 개요 (안내 시각화)

섬 모양의 개요입니다. 배치는 HTML/CSS 구성이며 "가까움"은 의미 거리 측정값이 아닙니다.

05구현 상태표 (30개 페이지)

공개 내비게이션은 R1(공개)만 노출합니다. R2/R3은 완성되기 전까지 예정으로 남습니다.

06가장 강한 반론 — 지도의 한계

실패 조건: 항로 추천이 "나를 꿰뚫어 본 추천"처럼 보이면 안 됩니다. 이 지도는 태그 매칭 규칙이며, 그래프 배치와 연결 수는 진실성·중요도 점수가 아닙니다. 추천 근거를 숨기지 않고, 항로는 출발점이지 시험이 아닙니다.
