기억과 망각 연구실

"완벽히 기억하는 시스템이 반드시 더 좋은 동반자인가?"

읽기 시간 약 10분 · 내용 성격: 검색 점수 실험 · 실행 모드: RULE_BASED(가상 기억 24개) · 검토일 2026-09-20

01이곳에서 무엇을 얻는가

가상의 기억 24개로 채워진 검색 샌드박스입니다. 키워드·태그·최근성의 가중치를 조정하면 같은 질문에도 어떤 기억이 올라오는지 달라집니다. 점수식과 검색 이유를 공개하고, 기억 수정·상충 해결·선택적 삭제를 실험한 뒤 삭제된 기억이 재검색에서 재등장하지 않는지 자동 검사합니다.

이 페이지는 실제 임베딩을 쓰지 않으므로 "벡터 검색"이라고 표시하지 않습니다. 기억 저장과 모델 가중치 학습은 별개입니다.

02검색 샌드박스

점수식(공개): score = 키워드가중치 × 키워드일치수 + 태그가중치 × 태그일치수 + 최근성가중치 × 최근성점수(최신 1.0 → 1년 전 0.0 선형 감쇠). 상위 5개를 표시합니다.

03수정·상충 해결·삭제

과거 기억 수정

기억을 선택해 내용을 고치면, 이후 검색에는 수정본만 나타납니다. (수정 이력은 남습니다)

상충 기억 해결

같은 사건을 다르게 기록한 두 기억 — 어느 쪽을 남길지 정합니다.

선택적 삭제 + 재등장 검사

기억을 삭제한 뒤 현재 검색을 다시 실행해, 삭제된 기억이 재등장하지 않는지 자동 검사합니다.

04결과 설명과 가장 강한 반론

관찰한 것 / 추론한 것 / 아직 모르는 것

관찰한 것: 가중치 변경에 따른 검색 순위 변화, 삭제 후 재등장 여부.
추론한 것: "더 많이 기억 = 더 좋은 동반자"라는 가정이 무조건 성립하지 않는다는 실감.
아직 모르는 것: 실제 임베딩 검색·실사용자의 기억 경험은 이 샌드박스로 대체되지 않습니다.

실패 조건: "삭제됨" 표시를 실제 삭제로 착각하는 것입니다. 삭제가 모든 사본(캐시·백업·외부 저장소)에 미친다는 보장은 구현과 일치해야 하며, 여기서 연습한 정책은 LayerAI Center의 기억 정책과 같은 기준을 따릅니다.

다음 질문 — 쉬운: "어떤 기억이 가장 오래 남아야 하는가?" · 반대: "망각이 오히려 더 나은 판단을 만드는 경우는?" · 먼 분야: "도서관의 폐기(weeding) 정책은 AI 기억 삭제 정책에 무엇을 가르치는가?"
