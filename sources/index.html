근거와 원전 도서관

"이 주장은 어디에서 왔으며 내가 직접 확인할 수 있는가?"

읽기 시간 약 8분 · 내용 성격: 서지·편집 해설 · 실행 모드: CURATED · 검토일 2026-09-20

01이곳에서 무엇을 얻는가

확장 페이지의 주장이 어느 문헌에서 왔는지 서지 정보와 인용 역할을 확인할 수 있습니다. "읽어볼 자료"와 "이 주장에 사용한 근거"를 구분하고, 요약 수준을 속이지 않습니다.

1차 원전 ↔ 편집 해설 구분

논문·원문과 이 사이트가 직접 쓴 해설을 항상 분리해 표시합니다.

인용 역할 명시

supports(지지) / challenges(반박) / background(배경) / fiction_reference(허구 참조) 중 하나를 붙입니다.

확인일 기록

링크·판본·발행일은 확인한 날짜를 남기고, 모르는 것은 "검토 대기"로 둡니다.

02원전 목록 탐색

유형·인용 역할·요약 수준으로 필터링합니다. 카드를 클릭하면 상세 정보가 펼쳐집니다.

결과 설명 — 관찰한 것 / 추론한 것 / 아직 모르는 것

관찰한 것: 필터에 맞는 문헌 목록과 서지 정보.
추론한 것: 각 문헌이 이 사이트의 어떤 주장을 지지·반박하는 배경인지는 편집자의 분류입니다.
아직 모르는 것: 초록만 읽은 항목은 상세 결과를 추정하지 않으며 "초록 수준"으로 표시합니다. 판본·발행일·라이선스는 공식 출처에서 재확인이 필요합니다.

03가장 강한 반론 — 편집 게이트

실패 조건: 문헌 하나를 "모든 주장의 근거"로 붙이면 이 도서관은 신뢰를 잃습니다. 공개 전 ① 제목·저자·판본·링크 확인 ② 원문에서 주장 대응 부분 확인 ③ 짧고 정확한 인용만 사용 ④ 번역·요약·해석·상상적 적용 구분 ⑤ 미확인 항목은 draft/review로 유지 — 이 다섯 단계를 지키지 않은 항목은 목록에 올리지 않습니다.
