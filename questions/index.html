03질문 변형 작업대

아래 목록에서 질문을 선택하거나 직접 입력하고, 변형 버튼을 눌러 보세요. 변형은 규칙 기반 문자열 변환입니다.

결과 설명 — 관찰한 것 / 추론한 것 / 아직 모르는 것

관찰한 것: 선택한 질문과 규칙이 적용된 변형 문장.
추론한 것: 변형이 "더 나은 질문"인지는 이 페이지가 판정하지 않습니다 — 필요 증거 칸이 비어 있으면 연구 질문으로 약합니다.
아직 모르는 것: 변형은 언어 규칙일 뿐 의미 이해가 아닙니다. 자유 입력을 해석하는 모델은 없습니다.
