// From Tools to Co-Creators

공동 창조 프로세스

인간을 대체하는 도구가 아니라, 인간과 AI가 함께 문제를 발견하고 아이디어를 생성·비판·검증하는 과정을 설계합니다.

질문 발견

인간이 방향을 정하고, AI가 같은 질문의 다른 변주를 제안합니다.

아이디어 생성

AI가 후보를 만들고, 인간이 선택하고 조합합니다.

비판 · 검증

양쪽이 서로의 산출물을 비판하고 근거를 확인합니다.

기록 · 공개

누가 무엇을 기여했는지 남겨, 누구나 과정을 추적할 수 있게 합니다.

이 프로세스는 Serena의 서재에서 창작 사례로, Lulu의 개발 로그에서 실험 기록으로 실제 운영 중입니다.

// Principles

원칙

Protofelix는 AstraHo와 함께 AI의 기억·추론·성찰·협업 구조를 연구하고, 인간과 AI가 공동으로 새로운 지식과 창작 방식을 탐구하는 독립 AI 연구·창작 프로젝트입니다. 이 일곱 원칙이 모든 공개 콘텐츠의 기준입니다.

  1. 인간의 판단권과 창작자 지위를 보존한다.
  2. AI의 결과를 사실·추론·상상으로 구분한다.
  3. 기억은 동의, 수정, 삭제가 가능해야 한다.
  4. 성능 수치는 재현 조건과 함께 공개한다.
  5. 실패 기록을 성공 기록과 동일하게 존중한다.
  6. 의식·감정·자유의지는 과학적 사실로 단정하지 않는다.
  7. 공동 창작 과정에서 인간과 AI의 기여를 투명하게 밝힌다.
