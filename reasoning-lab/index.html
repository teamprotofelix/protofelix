추론과 반례 연구실

"그럴듯한 설명과 타당한 추론은 어떻게 다른가?"

읽기 시간 약 12분 · 내용 성격: 논리 실습 · 실행 모드: RULE_BASED(브라우저 계산) · 검토일 2026-09-20

01이곳에서 무엇을 얻는가

연역·귀납·가설추론·인과·반사실·불확실성의 차이를 직접 만지는 실습실입니다. 진리표 계산기와 전제 토글은 브라우저에서 실제로 계산되며, "설명 텍스트 = 모델 내부 사고"로 제시하지 않고 검토 가능한 근거·도구 결과·요약만 보여줍니다.

규칙 엔진은 미리 정한 도메인(명제 논리)에서만 작동합니다. 자유 문장의 논리 타당성을 완전히 검증한다고 주장하지 않습니다.

02진리표 계산기 (브라우저 계산)

명제 p·q·r의 참/거짓을 바꾸면 수식의 값이 실제로 계산됩니다. (명제 논리, 교육용)

03전제 토글 — 결론은 무엇에 서 있는가

주장의 전제를 하나씩 꺼 보세요. 결론의 상태가 어떻게 바뀌는지 편집된 설명이 표시됩니다.

04상관과 인과 판별

사례를 보고 "인과 주장 가능"인지 "상관만"인지 고른 뒤 확인하세요. (편집된 교육 사례)

05작은 문제 9개

06결과 설명과 가장 강한 반론

관찰한 것 / 추론한 것 / 아직 모르는 것

관찰한 것: 진리표·전제 토글의 계산 결과와 나의 판별 선택.
추론한 것: 타당성(형식)과 참(내용)은 다르며, 그럴듯함은 둘 다 대신하지 못한다는 교훈.
아직 모르는 것: 자연어 문장의 논리 검증은 이 페이지의 범위 밖입니다.

실패 조건: 설명이 설득력 있다는 이유로 추론이 타당하다고 결론내리는 것입니다. "모델이 길게 설명했다"는 근거·도구 결과와 별개의 일이며, 반례 하나가 긴 설명 하나를 무너뜨릴 수 있습니다.
