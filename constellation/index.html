"아직 연결되지 않은 지식 사이에 무엇이 있는가?"

읽기 시간 약 8분 · 내용 성격: 지식 그래프 탐색 · 실행 모드: RULE_BASED(BFS 경로 탐색) · 검토일 2026-09-20

01이곳에서 무엇을 얻는가

개념·질문·작품·논문·실험의 노드 30개와 편집 관계 45개 위에서, 두 노드 사이의 최단 경로와 서로 다른 분야를 통과하는 우회 경로를 탐색합니다. 좌표 거리는 그래프 배치 결과이며 의미 거리가 아니고, 연결 수 또한 진실성 점수가 아닙니다.

관계 유형

supports(지지) · challenges(반박) · analogy(유사) · prerequisite(선행) · inspired_by(영감) — 선·배지·설명으로 구분합니다.

확인된 관계 vs 추천 관계

출처가 확인된 관계와 알고리즘 추천 관계를 배지로 구분합니다. 사용자 연결은 로컬에만 표시됩니다.

텍스트 목록 동일 기능

그래프 배치를 읽지 못해도 목록으로 모든 탐색이 가능합니다. 단절된 노드는 "단절됨"으로 표시됩니다.

03노드 지도와 목록

관계 범례와 단절 노드

supports = 지지 · challenges = 반박 · analogy = 유사 · prerequisite = 선행 · inspired_by = 영감.
확인된 관계 편집자가 출처를 확인한 관계 · 추천 관계 규칙 기반 제안(아직 편집 검토 전).
단절 노드(관계 0개)는 목록에 "단절됨"으로 표시되며, 추천 관계가 붙기 전까지 숨기지 않습니다.

04내 연결 추가 (로컬 표시)

사용자 연결은 공개 그래프에 반영되지 않으며 이 브라우저에서만 보입니다.

05결과 설명과 가장 강한 반론

관찰한 것 / 추론한 것 / 아직 모르는 것

관찰한 것: 무가중 BFS로 계산한 노드 경로와 관계 라벨.
추론한 것: "경로가 짧다 = 관련이 깊다"는 해석은 성급합니다 — 경로는 편집된 연결의 결과일 뿐입니다.
아직 모르는 것: 아직 연결되지 않은 노드 사이에 실제로 무엇이 있는지는 이 그래프가 말해주지 않습니다.

실패 조건: 연결 수를 진실성 점수로, 좌표 거리를 의미 거리로 읽으면 이 성좌는 지식을 왜곡합니다. 논문 관계 그래프의 지지 링크와 사용자의 상상적 연결은 동일한 실선으로 그리지 않으며, 추천 관계는 검토 전 상태로 표시됩니다.

다음 질문 — 쉬운: "내가 자주 함께 쓰는 두 개념 사이에는 어떤 관계가 있는가?" · 반대: "연결을 많이 가진 노드가 오히려 독창성을 가리는 것은 아닐까?" · 먼 분야: "지하철 노선도가 도시를 단순화하듯, 지식 그래프는 무엇을 단순화하는가?"
