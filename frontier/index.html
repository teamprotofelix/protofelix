인지경계 실험실

"같은 문제를 혼자 생각할 때와 도움을 받을 때 무엇이 달라지는가?"

읽기 시간 약 12분 · 내용 성격: 자기 관찰 실험 · 실행 모드: USER_AUTHORED(+편집된 설명 예시) · 검토일 2026-09-20

01이곳에서 무엇을 얻는가

독립 초안 → 잠금 → 보조 자료 공개 → 수정본 → 변화 기록 순서로, 도움을 받기 전과 후의 내 생각이 어떻게 달라지는지 기록합니다. 결과에는 baseline·assisted·references·rubric·limitations가 포함되며, 단어 수·수정 횟수 같은 수치는 기계로 계산되고, 유용성·새로움은 내 자기평가로만 남습니다.

순서가 실험의 핵심

보조 자료를 보기 전의 초안을 잠가야 비교가 성립합니다. 보조를 본 뒤의 초안은 "인간 단독 기준선"이 아닙니다.

교육 체험 ≠ 연구 주장

이 체험 결과는 연구용 비교가 아닙니다. 연구 주장은 반복·평가자·조건 통제가 있을 때만 가능합니다.

자동 점수처럼 위장하지 않음

기계 계산(단어 수 등)과 자기평가(유용성·새로움)를 분리해 표시합니다.

026종 실험 선택

03실험 진행

초안을 잠그면 편집된 보조 예시가 표시됩니다.

변화 기록: 수정본 입력 시 초안과 자동 비교해 단어 수·후보 수 차이를 표시합니다.

04자기평가와 기록 저장


자기평가는 "사용자 자기평가"로 표시되며 연구적 우월성을 주장하지 않습니다.

결과 설명 — 관찰한 것 / 추론한 것 / 아직 모르는 것

관찰한 것: 잠긴 초안, 보조 공개 시점, 수정본, 기계 계산 수치, 소요 시간.
추론한 것: "변화"의 의미는 내 해석입니다 — 보조가 도움인지 방해인지는 이 한 번의 체험으로 결론나지 않습니다.
아직 모르는 것: 무작위 순서·반복·평가자 통제 없이는 일반화할 수 없습니다. 검증과 증거의 조건을 참고하세요.

05가장 강한 반론 — 기준선의 함정

실패 조건: 보조 자료를 본 뒤의 수정본과 "독립 초안"을 비교하면서 초안 작성 시간·연습 효과·노출 순서를 무시하면, 이 비교는 아무것도 증명하지 못합니다. 이 페이지는 교육 체험이며, 결과를 연구 주장으로 쓰려면 반복·평가자·조건 통제와 별도 설계가 필요합니다.
