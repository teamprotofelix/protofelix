01이곳에서 무엇을 얻는가

다른 탐험 페이지에서 얻은 결과를 한곳에 모으고, Markdown/JSON으로 내보내 다른 기기에서 이어갈 수 있습니다. 저장은 이 브라우저에만 되며, 어떤 내용도 외부 서버로 전송되지 않습니다.

저장 위치를 명시합니다

IndexedDB(브라우저 로컬 저장소). 저장 불가 시 메모리+localStorage 폴백으로 동작합니다.

내보내기·가져오기

Markdown·JSON 다운로드, JSON 가져오기(스키마 검증, id 기준 중복 병합).

삭제 통제

항목별 삭제와 전체 초기화는 확인 절차를 거치며, 가져온 파일은 깨지면 거절합니다.

⚠ 브라우저 데이터 삭제·시크릿 모드 종료·저장 용량 초과 시 기록이 사라질 수 있습니다. 중요한 기록은 주기적으로 내보내세요. 기기 간 공유는 파일 내보내기/가져오기로 시작합니다. 개인정보·비밀은 적지 않는 것을 권장합니다.

02기록 추가

04내보내기·가져오기

내보내기

Markdown(읽기용)과 JSON(재가져오기용) 두 형식. URL에는 개인 본문을 넣지 않습니다.

가져오기 (JSON)

이 노트북에서 내보낸 JSON만 허용합니다. id 기준으로 중복을 병합하고, 최신 갱신일을 유지합니다.

정리

항목 삭제는 각 카드에서, 전체 초기화는 아래 버튼에서 — 확인 절차를 거칩니다.

05가장 강한 반론 — 저장의 한계

실패 조건: "저장됨"이 곧 "보존됨"은 아닙니다. 이 노트북은 브라우저 저장소이므로 브라우저 데이터 삭제·비공개 모드·용량 초과 시 기록이 유실될 수 있고, 기기 간 자동 동기화는 없습니다. 보존을 보장하지 않으며, 중요한 기록은 파일로 내보내 두는 것이 유일한 안전책입니다.
