01이곳에서 무엇을 얻는가

원작·영화·각색을 구분하고, 인물 소개보다 설계 쟁점을 중심으로 12개 작품을 편집했습니다. Solaris의 지성은 인간 제작 AI가 아닌 외계 지성으로 분류하는 등, AI·디지털 인격·외계 지성·사이보그를 구분합니다. 작품의 문장을 길게 전재하지 않고, 표지·스틸 대신 자체 제작 추상 이미지를 사용합니다.

판본·발행일·해석은 공식 출판사·원문 확인 후 확정합니다. 각 카드는 편집 후보이며, 스포일러가 포함됩니다.

04SF 설정 → 연구 가설 → 작은 실험

05결과 설명과 가장 강한 반론

관찰한 것 / 추론한 것 / 아직 모르는 것

관찰한 것: 작품들이 서로 다른 지성 형태를 상상했다는 사실과 필터 결과.
추론한 것: "허구의 설정"을 "검증 가능한 질문"으로 바꾸는 것은 편집자의 번역입니다.
아직 모르는 것: 작품의 세부 해석·판본 정보는 원문 확인 전까지 확정하지 않습니다.

실패 조건: SF 설정을 기술 로드맵이나 예언으로 바꾸면, 이 아카이브는 상상력을 죽이는 장소가 됩니다. 알려진 생물·집단 현상과 상상한 AI를 같은 수준의 사실로 두지 않고, 모든 복잡한 시스템을 의식 있는 존재로 분류하지 않습니다.
