열린 진화의 정원

"한 가지 점수를 잘 받는 것과 새로운 가능성을 발견하는 것은 같은가?"

읽기 시간 약 10분 · 내용 성격: 진화 탐색 실험 · 실행 모드: RULE_BASED(셀룰러 오토마타) · 검토일 2026-09-20

01이곳에서 무엇을 얻는가

셀룰러 오토마타 규칙 후보 8개가 세대를 거듭하며, 목표 적합도 / 행동 다양성 / 무작위 탐색 세 가지 선택 모드 아래 어떻게 달라지는지 비교합니다. 규칙 공간·개체 수·세대 수에 상한을 두고, 평가 횟수가 다른 실험은 나란히 표시하되 조건 차이를 밝힙니다.

"새로움"은 현재 아카이브 내 거리(Hamming)로 정의된 교육용 지표입니다. 인간 창의성·생명·의식을 측정하지 않습니다.

02진화 실험

모드와 조건을 고르고 실행하세요. 세대당 규칙 8개 — 평가 횟수는 모드 간 동일합니다.

03결과 설명과 가장 강한 반론

관찰한 것 / 추론한 것 / 아직 모르는 것

관찰한 것: 선택 모드별 세대 우승 규칙과 점수 변화 (브라우저 계산).
추론한 것: "하나의 점수만 쫓으면 다양성이 사라진다"는 직관이 이 작은 세계에서도 드러나는지.
아직 모르는 것: 실제 생물 진화·창의성 과정은 이 모형과 겹치지 않는 부분이 훨씬 큽니다.

실패 조건: 다양성 점수가 높다고 "더 창의적"이라고 말하는 것입니다. 이 정원의 새로움은 아카이브 내 거리라는 좁은 정의이며, 목표 적합도 모드가 나쁘고 다양성 모드가 좋다는 결론도 목표가 무엇인지에 따라 달라집니다 — 정원은 가능성의 아카이브이지 우열의 사다리가 아닙니다.

다음 질문 — 쉬운: "내가 '성과'로 추적하는 지표는 무엇을 선택에서 배제하는가?" · 반대: "다양성만 추구하면 아무것도 완성되지 않지 않는가?" · 먼 분야: "미술관 큐레이션의 '소장 다양성' 기준은 탐색 알고리즘의 아카이브 설계에 무엇을 주는가?"
